# Implementación inicial de clases de Imagen Dental 3D

## Descripción y justificación

1. Mi proyecto Imagen Dental 3D (ID3D) busca gestionar y entregar estudios de imagen dental.
2. Su propósito es organizar la información y facilitar el acceso controlado a los estudios.
3. El diseño considera pacientes, usuarios, roles, tipos de estudio, archivos y autorizaciones.
4. La solución está prevista para utilizarse desde dispositivos móviles y navegadores web.
5. Elegí JavaScript para mantener un mismo lenguaje en las distintas capas del proyecto.
6. En esta actividad implemento clases, constructores y métodos mediante programación orientada a objetos.
7. Utilizo Node.js para ejecutar y comprobar el comportamiento del modelo por consola.
8. Seleccioné Visual Studio Code por su asistencia para JavaScript y herramientas de depuración.
9. Para las interfaces posteriores se contemplan React Native, Expo y React Native Web.
10. La persistencia posterior utilizará MySQL con InnoDB, conforme al diseño de base de datos.
11. Esta entrega valida publicación de estudios y vigencia de permisos con datos ficticios en memoria.
12. El código, el diagrama actualizado y las instrucciones de ejecución se incluyen en el repositorio.

## Diagrama y codificación

Presento una versión actualizada del diagrama de clases de ID3D,
acompañada de su implementación en JavaScript. Las pruebas verifican publicación,
revocación, vencimiento y estado de las cuentas. El README explica cómo ejecutar la
implementación y delimita las funciones pendientes.
